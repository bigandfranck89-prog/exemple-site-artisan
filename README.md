# Site d'exemple pour un artisan

Site de démonstration : l'artisan « Atelier Peinture Exemple » est fictif, le logo et les photos sont des emplacements.
Il montre à quoi ressemble un site simple, lisible sur téléphone, pour un artisan qui n'en a pas encore.

En ligne : https://exemple-site-artisan.netlify.app (déposé à la main sur Netlify ; ce dépôt garde la copie de référence).
